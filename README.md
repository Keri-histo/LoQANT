Installation
1. Download Fiji:
Download the latest version of FIJI at https://imagej.net/software/fiji/downloads according to your operating system and install it.

2. Download LoQANT
  a.	Download the LoQANT_.py file from this repository
  b.	Find the Fiji.app folder on your computer. 
  c.	Open the Fiji.app folder and place LoQANT_.py file to folder called „plugins“. 
  d.	Launch Fiji and LoQANT is now to be found in Plugins menu. (Note: If the Fiji has been already open, it needs to be restarted.)

For detail, please follow the User Manual provided in this repository.
