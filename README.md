Installation
Download Fiji: 
1. Download the latest version of FIJI at https://imagej.net/software/fiji/downloads according to your operating system and install it.

Download LoQANT:
1. Download LoQANT_.py and LoQANT_batch.py files from this repository. Find the Fiji.app folder on your computer. 
2. Open the Fiji.app folder and place LoQANT_.py and LoQANT_batch.py file to folder called „plugins“. 
3. Launch Fiji and LoQANT is now to be found in Plugins menu. (Note: If the Fiji has been already open, it needs to be restarted.)

For details, please follow the User Manual provided in this repository. The user manual has been updated for LoQANT_batch usage.
